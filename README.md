# Finance — CS50 Week 9

A Stock Trading Simulation Web Application built as part of Harvard University's CS50 course.

## Overview

Finance is a web application that simulates stock trading using virtual money. Users can create an account, look up stock prices, buy and sell shares, and track their portfolio without risking real money.

The application starts users with a virtual balance of **$10,000**, allowing them to practice stock trading and understand how transactions affect their available cash and portfolio value.

## Features

- **User Registration and Login** — Create an account and securely access a personal portfolio.
- **Stock Lookup** — Search for stocks and view their current quoted prices.
- **Buy Shares** — Purchase shares using virtual funds.
- **Sell Shares** — Sell owned shares and update the portfolio balance.
- **Portfolio Tracking** — View owned stocks, share quantities, and portfolio values.
- **Transaction History** — Review previous stock transactions.
- **Virtual Cash Balance** — Practice trading without using real money.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja Templates

## How It Works

1. Register for an account and log in.
2. Look up a stock to check its quoted price.
3. Buy shares using the available virtual balance.
4. Review the portfolio and monitor its value.
5. Sell shares when desired and review the transaction history.
